# Sijin S — Portfolio

Next.js 16 · TypeScript · Tailwind CSS 4 · Motion

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
```

## Where things live

- `content/profile.ts`: all resume content. Edit this file to update the site.
- `app/page.tsx`: the page layout
- `components/Sections.tsx`: hero, stats, experience, tech specs, contact and footer
- `components/Showcase.tsx`: the project sections; `components/Mockups.tsx` holds the animated product mockups
- `app/opengraph-image.tsx`: the preview image shown when the link is shared
- `public/Sijin_S_Resume.pdf`: the downloadable resume

## Deploy

Push to GitHub, then import the repository at vercel.com/new. No configuration is needed.
